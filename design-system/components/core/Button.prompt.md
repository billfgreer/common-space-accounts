Primary action button — use for any CTA; `circle` is the signal-yellow round "About >>" call, `link` is the yellow-underlined inline link.

```jsx
<Button variant="primary" href="/join">Join us</Button>
<Button variant="circle">About</Button>
<Button variant="outline" chevron>Donate</Button>
<Button variant="link">Read the mission brief</Button>
```

Variants: `primary` (ink fill, yellow chevron) · `outline` (ink hairline) · `circle` (yellow round CTA) · `link` (yellow underline).
